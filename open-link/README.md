# Страница открытия ссылок 1С (`open-link/`)

Статическая страница, которая открывает навигационную ссылку 1С щелчком по обычной https-ссылке - так же, как ссылка на встречу Zoom открывает приложение Zoom.

Зачем: AI-клиенты (Claude Code, Cursor и др.) и трекеры делают кликабельными только `http(s)`, а ссылки `e1c://...` показывают текстом. Страница принимает ссылку в адресе после `#` и переходит на `e1c://`, а Windows передаёт её `1cestart.exe`, который открывает объект в нужной базе.

## Формат ссылки

```
https://<сайт>/<приложение>/#server/<сервер>/<база>#e1cib/<раздел>/<путь>
```

Например: `https://example.com/e1c/#server/srv-1c/ut#e1cib/list/Документ.ЗаказКлиента`.

Часть после `#` браузер на сервер не отправляет, поэтому в журналах веб-сервера ссылок нет.

## Что проверяет страница

- Разделы - только `e1cib/list`, `e1cib/data`, `e1cib/navigationpoint`; `e1cib/command` и прочее не открывается.
- Сервер - только внутренний: имя без точек (`srv-1c`, можно с портом) или имя в домене самой страницы. Страница на `portal.example.com` пропускает `*.example.com`, но не `example.com.evil.org`. Иначе подставленная ссылка могла бы увести клиент 1С с доменной аутентификацией на чужой сервер. IP-адреса и другие домены не пропускаются; список серверов через запятую тоже.
- Автоматический переход - только из видимой вкладки и один раз. Неотвеченный вопрос «Открыть приложение?» в фоновой вкладке заставляет Chrome молча гасить все следующие запуски приложений. Если переход не сработал, есть кнопка «Открыть в 1С»: повторный запуск без щелчка пользователя браузер блокирует.

На странице также:

- инструкция, как открыть ссылку вручную («Перейти по ссылке…» в главном меню 1С или в окне запуска) - с короткой и полной ссылкой и кнопками «Скопировать»;
- регистрация протокола `e1c://` для текущего пользователя, без прав администратора: файл `e1c-register.reg` или команды `reg add` для `cmd`.

## Установка в IIS

1. Скопировать содержимое папки (кроме `tools/` и `README.md`) в каталог приложения, например `C:\inetpub\e1c`.
2. Создать приложение на сайте с HTTPS: `appcmd add app /site.name:"Default Web Site" /path:/e1c /physicalPath:C:\inetpub\e1c`.
3. Включить анонимную аутентификацию и выключить Windows-аутентификацию для приложения: страница статическая, а вопрос пароля перед переходом в 1С только мешает.

`web.config` включает документ по умолчанию и отдаёт `.reg` как `application/octet-stream`, чтобы браузер скачивал файл, а не показывал его текстом.

Подойдёт любой веб-сервер со статикой; для другого сервера нужен свой аналог `web.config`.

## Ссылки из MCP

Если в настройках клиента MCP задан заголовок `X-1C-Open-Link-Base` с адресом страницы, HTTP-сервис передаёт его инструментам в аргументе `_context` (`openLinkBase`). Инструменты расширения [Ei](https://github.com/German09/Ei) добавляют по нему поле `url` в описания ссылок и ключей записей - готовую https-ссылку в формате выше. В базах, подключённых не через кластер серверов (файловая, автономный сервер), `url` не формируется: ссылку `e1c://` нельзя привязать к базе.

```json
"headers": {
  "Authorization": "Basic <Base64Строка>",
  "X-1C-Open-Link-Base": "https://example.com/e1c/"
}
```

## Картинки

`menu-go-to-link.png` и `launcher-go-to-link.png` размечены скриптом `tools/annotate-screenshots.ps1` (рамки, стрелки, номера, имя пользователя заменено). Исходные снимки в репозитории не хранятся: на них настоящее имя пользователя. Чтобы переснять, сохраните снимки главного меню (`11.png`) и окна запуска (`10.png`) в одну папку, поправьте координаты в скрипте под свои снимки и выполните:

```powershell
powershell -File tools\annotate-screenshots.ps1 -ImagesDir <папка со снимками> -OutDir .
```
