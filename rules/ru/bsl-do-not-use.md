# Обход коллекций

> Источник: [Confluence — Не используем](https://confluence.askona.ru/pages/viewpage.action?pageId=123273438) (`~g.kudiakov`).

## По умолчанию — цикл

Для обхода коллекции **используем** `Для Каждого`:

```bsl
Для Каждого Элемент ИЗ Массив Цикл
	// обработка
КонецЦикла;
```

## Не используем — квадратные скобки с числом

**Не используем** обращение через **квадратные скобки с числовым индексом** — `Массив[0]`, `Таблица[Индекс]` и т.п. Это единое ограничение на синтаксис `[]` с числом.

```bsl
// Неправильно
Элемент = Массив[0];
```

## Особый случай — `Получить(Число)`

`Массив.Получить(0)` (и аналогичный доступ по числу через `Получить`) — **не запрещён**. Применяй, когда обход циклом **затруднён** или неуместен: нужен один конкретный элемент, контракт API, индекс уже вычислен снаружи цикла.

```bsl
// Цикл затруднён: известно, что нужен единственный элемент ответа
Параметр = ОтветСервиса.items.Получить(0);
```

Не подменяй цикл `Получить(0)` «для удобства», если `Для Каждого` читается нормально.
