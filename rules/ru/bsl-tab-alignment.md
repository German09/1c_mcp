# Выравнивание Tab в BSL

В **группах связанных строк** выравнивай оператор присваивания (`=`) и аргументы однотипных вызовов **табами** (не пробелами).

## Границы группы

Группа — только **непрерывные** строки присваиваний или однотипных вызовов. Любая другая конструкция (`Если`, `Пока`, `Для`, `Попытка`, `Возврат`, пустая строка с логикой) **завершает** текущую группу. Следующая группа выравнивается **заново**, по самому длинному элементу **только внутри неё** — не переноси ширину из предыдущего блока.

```bsl
// Неправильно — одна ширина на весь метод, хотя между блоками есть Если:
Результат			= Новый Структура(...);
Ссылка				= ...;
Если ... Тогда
	Возврат Результат;
КонецЕсли;
СтрАдреса			= ...;
ПараметрыЗапроса 	= Новый Структура;

// Правильно — два независимых блока:
Результат 	= Новый Структура(...);
Ссылка		= ...;
Если ... Тогда
	Возврат Результат;
КонецЕсли;
СтрАдреса			= ...;
ПараметрыЗапроса 	= Новый Структура;
```

## Группы присваиваний

Подряд идущие присваивания с общим смыслом (инициализация, подготовка параметров) — в одну колонку `=` в пределах группы:

```bsl
СтрАдреса			= КоординатыПовтИсп_POS5000.ПолучитьСтруктуруАдреса();
ПараметрыЗапроса 	= Новый Структура;
```

Длина левой части — по самому длинному идентификатору **в этой группе**; между именем и `=` — табы.

## Однотипные вызовы методов

Повторяющиеся вызовы с одинаковой структурой (например, `Структура.Вставить`) — выравнивай значения аргументов после запятой **в пределах своей группы**:

```bsl
ПараметрыЗапроса.Вставить("dimension_type", Размер(Крупногабаритный));
ПараметрыЗапроса.Вставить("target_lat", 		Широта);
ПараметрыЗапроса.Вставить("target_lon", 		Долгота);
```

То же для документирующих комментариев с параметрами (`//  Имя - Тип - Описание`).

## Когда не выравнивать

- Одиночное присваивание вне группы.
- Не выравнивай весь файл за один проход — только новый и изменённый код.
