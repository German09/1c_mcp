# Проект 1c_mcp

## Конфигурация

- **Продукт:** расширение MCP-сервера для 1С (`MCP_Сервер`)
- **EDT-проект:** `УТ.MCP` (исходники в `src/edt/src/`)
- **Префикс объектов:** `mcp_`
- **БСП:** не является обязательной зависимостью расширения; `bsl-ssl.md` применяй только если правка затрагивает конфигурацию с БСП
- **MCP-сервер:** EDT MCP Server (`user-EDT MCP Server`) — чтение/запись BSL и метаданных только через его инструменты
- **Язык общения с пользователем:** русский
