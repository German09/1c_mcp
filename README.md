# 1C MCP Tools

> 🔧 **Maintained fork** проекта [1c_mcp](https://github.com/vladimir-kharin/1c_mcp) — инструмент для создания MCP-серверов на платформе 1С:Предприятие.

## Отличия от оригинала

### 🔍 Инструмент работы с запросами

Позволяет AI-модели **автономно исследовать данные** в базе 1С:

- **Произвольные запросы** — выполнение любых запросов для получения данных
- **Итерационный анализ** — модель анализирует результаты и при необходимости делает дополнительные запросы
- **Навигационные ссылки** — можно дать модели ссылку на объект и попросить найти связанные данные
- **Генерация ссылок** — модель может сгенерировать навигационную ссылку по найденным данным

> [!CAUTION]
> **Безопасность данных:** При использовании AI-моделей для запросов к базе данные передаются на внешние серверы. Убедитесь, что:
> - Не запрашиваете персональные данные (ФИО, паспорта, адреса, телефоны)
> - Используете локальные LLM для работы с конфиденциальными данными
> - Ограничили права пользователя, от имени которого выполняются запросы
> - Рассмотрите возможность доработки обфускации данных перед отправкой в LLM
